# Laços e Flores — catálogo online

Catálogo de cestas personalizadas, flores e balões da **Laços e Flores** (Triunfo – RS):
presentes prontos, **Monte sua cesta** (as cestas são liberadas conforme a quantidade de itens),
sacola com frete por região, pedido pelo WhatsApp e painel da loja (`#admin`).

- Site: `index.html` (publicado pelo GitHub Pages)
- Demonstração em arquivo único: `Demonstracao.html`
- Detalhes, painel e o que revisar: [LEIA-ME.md](LEIA-ME.md)

Site desenvolvido por TF Solutions.
